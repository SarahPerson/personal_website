If you know me, you likely have recieved a Ted Talk about the lore and theories around the Legend of Zelda series - research courtesy of the bible of Zelda "Hyrule Historia" and many years of religiously following ZeldaDungeon.net and participating in their forums. Not a new wave "I over-built this complex machine to solve this shrine puzzle in the exact same way I solved every other puzzle in this game but wow this game is amazing" Tears of the Kingdom fan. But I loved the idea of the passage of time on my PC so I thought "hey, this shouldn't be too hard to do myself, right?". And thus started an adventure of lots of tangents and way to much effort for such a small thing. Sometimes however it is the smallest tasks that you learn the most from. 

On Windows, there are many different third party softwares available that I could have purchased to change automate my background changing. But I also thought there must be a way to do this myself. The following details the various attempts I made to accomplish this goal without outside software and the many lessons I learned along the way. 

## Using Windows Task Scheduler
My first thought to approach this problem was to schedule a task that would change the background of my machine. In Linux world, this can be done simple using CRON. CRON is a super powerful tool that allows you to schedule practically any task you want to run on your computer. You can specify tasks to run at intervals or at specific times. Windows has something *similar* in task scheduler. You can schedule tasks to run programs or powershell scripts. You set a trigger for that task, 
* Simplest approach to make a task that changes the background at fixed times of the day 
    * 4 tasks each
* Use BGi to create the background file that would be called as the action of the tasks Scheduler
* Problems with this approach
    * task scheduler isn't intuitive for what it should do when the pc is asleep
    * you can schedule a task to run while asleep but it isn't always consistent, at least how I configured it
    * you can have the task run the next time the pc is on but that creates weird race conditions when say you don't use your computer for over 12 hours and the morning noon and evening task all run at the same time. More often than not my background would change multiple times in a second and still end up with the wrong one 
    * This doesn't let me set the lock screen! Backgrounds are nice and all, but how often do you actually see your background? I way more often look at my lock screen and ideally need this to match my background image

## Create a Powershell Script 
* Script would call a windows dll to update the background 
* It also exposed a way to update the lock screen image by setting some register values. Register values compared to environment variables in Linux
* This was great, easy to read, easy to understand, and could be scheduled by Task Scheduler
* Problems 
    * EVERY TIME THE STUPID SCRIPT RUNS THE STUPID POWERSHELL WINDOW POPS UP OVER WHATEVER I AM DOING UGH
    * The settings refresh isn't always "heard" by windows so the background doesn't always change
